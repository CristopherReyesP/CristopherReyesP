## About me

I started out wanting to understand every layer of a web application: databases, servers, deployment, backend and frontend. That curiosity is still there, but my main focus today is backend engineering, especially APIs, distributed systems and production workloads. I still value understanding the full software lifecycle, from the database schema to the deploy pipeline.

## What I work on

- APIs and microservices with NestJS and .NET (C#) for banking and payments.
- Oracle databases behind those services.
- Integrations between systems with MuleSoft, RabbitMQ and Keycloak.
- Deployments on OpenShift/Kubernetes with Docker and CI/CD pipelines.

## Problems I like to work on

- Operations that must stay consistent across services.
- Moving legacy systems forward without stopping the business.
- Integrations between systems with different contracts and owners.
- APIs other teams can rely on: clear contracts, predictable errors and secure access.
